CineHub is a student project for the Web Programming 2 course. It is a catalog of 20 movies and 20 series loaded from JSON files, with search, sorting, filtering, a favorites list saved in the browser (localStorage) and a contact form. Built with HTML, CSS, JavaScript and jQuery.
